Markets

Retrieve a list of tracked commodity markets across Nigeria, including geographical metadata and operational status.

GET /v1/markets

The Markets endpoint provides a catalog of physical marketplaces monitored by PriceNaija. Each market is assigned a unique `market_id` which is required when querying specific price observations via the Prices API.

Query Parameters

Parameter Type Description
state string Filter markets by Nigerian state (e.g., Lagos, Kano).
limit integer Maximum number of records to return. Default: 50. Max: 100.
status string Filter by operational status (active, inactive).

Using Market IDs

Once you have identified the market_id (e.g., mkt_mile12_lag) from this endpoint, you can use it to filter commodity prices in the Prices endpoint arrow_forward.

lightbulb

Pro Tip: Market Coverage

Currently, major markets like Wuse (Abuja), Mile 12 (Lagos), and Kurmi (Kano) have daily observation updates. Regional markets may report bi-weekly.
