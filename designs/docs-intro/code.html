Introduction

Welcome to the PriceNaija API. Our API provides programmatic access to real-time and historical food price data across major Nigerian markets.

Base URL

All API requests should be prefixed with the following base URL:

https://api.pricenaija.com/v1
{{DATA:COMPONENTS:COMPONENTS_11}}
{{DATA:COMPONENTS:COMPONENTS_12}}

Example Request

cURL 
curl -X GET \
  'https://api.pricenaija.com/v1/commodities/rice/prices?market_id=lag-01' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Accept: application/json'
